# 基于单波束声呐和单目视觉结合的水下环境感知研究

## 项目简介

本项目实现了一套面向轻量化自主水下航行器（AUV）的“精确感知—语义理解—智能决策”完整技术链。系统通过深度融合单目相机与单波束回声测深仪（SBES），生成尺度准确的稠密深度图；在此基础上构建像素级态势感知模型，输出“危险/警告/安全”三分类语义图；最终将态势信息嵌入模型预测控制（MPC）框架，实现风险预见性自主避障。

### 主要功能

1. **多模态深度估计网络**：提出残差高斯扩散（RGD）机制，利用稀疏SBES绝对深度校正单目相对深度，生成高分辨率、度量准确的深度图。
2. **时空语义态势感知模型（SA-Net）**：融合RGB、深度图与动态差异图，通过双分支注意力U-Net输出像素级安全等级评估。
3. **态势感知驱动的MPC框架（SA-MPC）**：将语义风险势场与概率动力学模型嵌入MPC优化，实现感知-决策-控制闭环。
4. **数据集与验证**：整合FLSeaVI、Sea-thru公开数据集，并构建UVSA视频态势评估数据集；在HoloOcean仿真与青岛近海实船上验证性能。

## 代码说明

- **`Code/ZoeDepthmain/`**：深度估计模块。包含基于DINOv2的编码器、DPT解码器及残差高斯扩散（RGD）融合代码。`train_mix.py` 和`train_mono.py` 用于训练，`evaluate.py` 用于评估。
- **`Code/UWAmodel_2/`**：态势感知模块（SA-Net）。实现双分支注意力U‑Net，融合RGB、深度图与动态差异图，输出像素级三分类态势图。`finaltrainunet.py`用于训练和验证。
- **`Code/HoloOceanSimulation/`**：HoloOcean安装环境，仿真与MPC控制模块。包含概率动力学模型训练、风险势场构建及SA‑MPC控制器，支持在HoloOcean环境中运行仿真。
- **`Code/run_depth_evaluation.py`**：集成后的单张图像深度估计推理脚本，用于测试单帧处理速度和可视化结果。
- **`Code/main.py`**：系统主入口。支持两种运行模式：`--mode sim`（连接HoloOcean仿真）和 `--mode real`（读取真实相机与SBES数据，输出深度图、态势图及控制指令）。

## 数据集说明

- **`Dataset/FLSeaVI/`**：公开水下深度估计数据集，含22451帧RGB图像及SfM深度真值，用于深度模型预训练。
- **`Dataset/Sea-thru/`**：公开水下去散射图像数据集，共1205张带深度真值的图片，用于深度估计的泛化测试。
- **`Dataset/UVSA/`**：自建水下视觉态势评估视频数据集，包含326个视频片段及像素级“危险/警告/安全”标注，用于训练SA-Net。
- **`Dataset/CalibData/`**：自建标定数据集，在室内水池同步采集的RGB图像与P30E声呐距离数据，用于传感器融合验证。
